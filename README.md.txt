# Transmission Fault Line Detection using ESP32 and Blynk

## Project Overview
This project detects faults in transmission lines using ESP32 and the Blynk IoT platform.

## Features
- Real-time fault detection
- Blynk cloud monitoring
- Relay protection system
- Buzzer alert system
- ESP32 based controller

## Components Used
- ESP32
- Relay Module
- Buzzer
- Blynk IoT
- Power Supply
